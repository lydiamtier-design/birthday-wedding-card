# 生日与婚礼 · 一张可以闯关的电子贺卡

一个纯前端、零依赖的中文电子贺卡模板。三个版本：**闯关版**、**长信版**、**经典版**。
所有资源内联在单个 HTML 里，双击就能看，也可以直接丢到任意静态托管上。

**在线看**：<https://lydiamtier-design.github.io/birthday-wedding-card/>

> 仓库里的文案是一份脱敏后的示例：人名、地名、日期、照片都已替换成占位内容。

## 三个版本

| 文件 | 说明 |
| --- | --- |
| `index.html` | 闯关版。六道小关卡（启封 → 吹蜡烛 → 童年 → 那段路 → 两天 → 接喜字），通关后打开一封信，结尾放红金烟花。 |
| `letter.html` | 长信版。一页到底的滚动叙事，适合手机阅读。 |
| `classic.html` | 经典版。常规落地页结构：首屏 → 故事时间轴 → 生日 → 婚礼 → 页脚。 |

## 特性

- **单文件自包含**：无框架、无构建、无 CDN，图片与音频都内联，断网可用。
- **手机优先**：`clamp()` 排版、触摸拖拽、`viewport-fit=cover` 适配刘海屏。
- **可访问性**：尊重 `prefers-reduced-motion`，打开「减弱动态效果」时不播放动画。
- **音效合成**：关卡音效用 WebAudio 现场合成，不依赖音频文件。
- **无追踪**：不加载任何第三方脚本或统计。

## 怎么改成你自己的

1. **日期**：搜索 `MM.DD`，替换成你们的日子（闯关版首页卡片、第五节的两张日历卡、时间轴、请柬图注都有）。
2. **照片**：搜索 `照片占位`，把 `<img src="data:image/svg+xml,...">` 换成你自己的图片路径，或重新内联成 base64。
3. **人名与称呼**：搜索 `你`、`一位老朋友`、`阿姨`，换成你们实际的叫法。
4. **文案**：三个页面的文字都是普通 HTML，直接改就行。信件正文在 `<div class="letter">` 里。
5. **结尾烟花**：搜索 `结尾烟花`，可调 `PAL`（配色）、`GOLD`（金色系）、`COUNT`（发数）。
6. **背景音乐**：模板默认没有音乐。想加就放一个 `<audio id="bgm" loop>` 并接一个按钮，注意商用音乐有版权限制。
